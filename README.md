# wak3up society — film credits

Image and footage credits for every film on the channel, generated from each
film edit by `scripts/build_credits_page.py` in the documentary pipeline.

Every row is one asset the film actually cut to, with its author, its licence
linked to the licence deed, and a link to where it came from.

Served at https://toolbeltios.github.io/wak3upsociety-credits/
